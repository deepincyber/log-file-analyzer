# Log File Analyzer

A beginner-friendly Python project that analyzes log files to identify useful security-related information and suspicious activity.

## Project Goal

The goal of this project is to understand how security logs can be processed and analyzed to identify patterns that may require further investigation.

## Planned Features

- Read and parse log files
- Count different types of log events
- Identify failed login attempts
- Identify frequently occurring IP addresses
- Generate a simple summary report
- Detect potentially suspicious patterns
